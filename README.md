# 🎯 Guess My Number

A simple interactive number-guessing game built with **HTML, CSS, and JavaScript**.

The player tries to guess a secret number between 1 and 20. The game provides feedback after each guess and keeps track of the player's score.

## 🚀 Live Demo

[Play Guess My Number](YOUR-LIVE-DEMO-LINK)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## 🎮 How to Play

1. Enter a number between **1 and 20**.
2. Click **Check**.
3. The game tells you whether your guess is:

   * Too high
   * Too low
   * Correct
4. Try to find the secret number before your score reaches zero.
5. Click **Again!** to start a new game.
